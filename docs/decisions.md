# Решения и риски

- Этапы выполняются последовательно по предоставленному ТЗ; текущая граница — инфраструктура и профиль. Задачи и календарь новой версии пока не реализованы.
- Next.js 15 с актуальным патчем выбран для поддерживаемой сборки; версии закреплены lockfile. Деплой остаётся Netlify, поскольку пользователь уже подключил его; переход на Vercel не требуется.
- Email/password Supabase Auth, подтверждение email управляется настройками Supabase. Минимум 8 символов на UI; такую же политику необходимо установить в Supabase.
- Прямой SDK + RLS обеспечивает серверную авторизацию и ограничения БД. Нет необоснованного обещания дополнительного API сервера.
- Нет доступа к реальному Supabase: не утверждаем, что auth/RLS/сохранение проверены в облаке. Тестовая среда должна иметь два отдельных аккаунта.
- Персональные сведения из ТЗ не помещаются в репозиторий или демо. Seed — позднее, с просмотром и подтверждением, только в приватные пользовательские данные.
- Текущее приложение заменяет старый статический интерфейс только после деплоя Next.js; перед этим нужно изменить настройки Netlify и подключить Supabase.
- До релиза остаются E2E реального auth, восстановление пароля, удаление аккаунта/экспорт, остальные этапы ТЗ. Не предлагается использовать этап 1 как завершённый планировщик.

## Этап 2
Профиль и вход пользователь подтвердил на действующем сайте. Задачи и календарь добавлены отдельной миграцией; проверка hosted Supabase остаётся после её применения. Автоматическое распределение дня не выдаётся за ручную ленту. На мобильном — нижняя навигация с дополнительным меню. Стек тестов дополнен Temporal, PGlite и Playwright с закреплёнными версиями.
