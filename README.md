# lifeOS

Первая версия личного планировщика: календарь, задачи по дням и 25-минутный таймер фокуса с паузой и сбросом.

## Разработка

Требуются Python 3 и Node.js 18+ (для тестов). Внешних зависимостей нет.

```sh
cd /workspace/lifeOS
npm start
```

Сервер слушает порт 3000. Проверка: `curl --fail http://127.0.0.1:3000/`.
Тесты логики календаря и таймера: `npm test`.

Задачи сохраняются в localStorage текущего браузера. Данные не синхронизируются между устройствами; очистка данных сайта удаляет задачи. Таймер учитывает реальное прошедшее время, в том числе при неактивной вкладке; после перезагрузки страницы сессия сбрасывается. Аккаунтов, уведомлений и серверного хранилища пока нет.
